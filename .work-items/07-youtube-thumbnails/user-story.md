# User Story: YouTube Thumbnails

## User Persona
**Name:** End User
**Description:** Someone seeking related video content to supplement text answers.

## Story
**As an** End User
**I want to** see related YouTube videos for my query
**so that** I can explore video content on the topic

## Acceptance Criteria (EARS Format)
- WHEN I submit a query THEN I SHALL see 4 YouTube video thumbnails
- WHEN I click a thumbnail THEN I SHALL navigate to the YouTube video
- IF no videos are found THEN I SHALL see a message indicating this

## Success Metrics
- ✅ YouTube API returns relevant videos
- ✅ Thumbnails display correctly
- ✅ Links open in new tab
