# User Story: Download as Markdown

## User Persona
**Name:** End User
**Description:** Someone who wants to export answers for offline use or documentation.

## Story
**As an** End User
**I want to** download answers as Markdown files
**so that** I can save them for offline reference or include in documentation

## Acceptance Criteria (EARS Format)
- WHEN I view an answer THEN I SHALL see a download button
- WHEN I click download THEN I SHALL receive a .md file
- WHEN I open the file THEN I SHALL see the answer with proper Markdown formatting
- WHEN citations exist THEN I SHALL see them as Markdown links

## Success Metrics
- ✅ Download triggers file save
- ✅ Markdown formatting is correct
- ✅ Citations are properly formatted
