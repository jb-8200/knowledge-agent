# User Story: Similar Questions

## User Persona
**Name:** End User
**Description:** Someone exploring a topic and wanting to discover related questions.

## Story
**As an** End User
**I want to** see related questions suggested by the system
**so that** I can explore different aspects of my topic

## Acceptance Criteria (EARS Format)
- WHEN I receive an answer THEN I SHALL see up to 5 related questions
- WHEN I click a suggested question THEN I SHALL submit it as a new query
- IF no related questions exist THEN I SHALL not see the section

## Success Metrics
- ✅ LLM generates relevant follow-up questions
- ✅ Questions are clickable
- ✅ Clicking triggers new search
