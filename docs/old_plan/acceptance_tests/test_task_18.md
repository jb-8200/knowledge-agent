# Acceptance Test for Task 18 – Design the HTML/CSS layout

**Objective:** Confirm that the front‑end presents a clear, white‑themed interface similar to the Google Search home page and includes all required sections.

**Test Steps:**

1. Open the web page in a modern browser.
2. Verify that the layout has a simple white background with a central search bar and a submit button.
3. Submit a query and ensure that the page displays sections for: the answer with numbered citations, links to relevant internal documents, links to external resources, four YouTube thumbnails, similar questions and pinned notes.
4. Check that the page is responsive and renders correctly on both desktop and mobile widths.
5. Inspect the page’s HTML/CSS for semantic structure and adherence to accessibility standards (e.g., proper ARIA attributes).

**Expected Result:** The interface is minimalist, visually clean, and includes all specified sections with proper styling and accessibility considerations.
