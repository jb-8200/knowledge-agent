# Acceptance Test for Task 20 – Render dynamic content

**Objective:** Ensure that the front‑end dynamically renders answer content, citations, thumbnails, related questions and pinned notes.

**Test Steps:**

1. After receiving a response from the backend, verify that the answer text appears in the designated area with citation markers hyperlinked to footnotes.
2. Confirm that a list of internal document links and external resource links is generated beneath the answer.
3. Check that up to four YouTube thumbnail images are displayed with clickable links to their videos.
4. Verify that the “People with similar question also asked” section lists up to five follow‑up questions; clicking one should send it as a new query.
5. Pin an answer and observe that a short note appears in the pinned area; ensure that it persists across subsequent queries in the same session.

**Expected Result:** Dynamic elements are rendered correctly and interactively respond to user actions.
