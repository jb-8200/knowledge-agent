# Task 18 – Design the HTML/CSS layout

**Phase:** User Interface

**Description:**

Design a minimalistic single‑page interface using HTML and CSS that resembles the simplicity of Google’s home page.  The page should include a search bar with a submit button, an answer display area, lists for internal documents and external links, a section showing four YouTube thumbnails, a list of follow‑up questions, and an area for pinned notes.  Use a white background and clean typography.  Include placeholders for dynamically populated content and ensure the layout is responsive on desktop and mobile browsers.

**Acceptance Criteria:**

* The HTML page loads and displays correctly with placeholder content.
* The layout is clean, centred and responsive.
* There are clearly defined sections for answer, citations, external links, YouTube thumbnails, similar questions and pinned notes.
* CSS styles use semantic classes and avoid external frameworks (except a simple reset if necessary).
